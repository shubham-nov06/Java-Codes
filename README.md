# JavaScript

A beginner-friendly collection of JavaScript and HTML practice files organized by chapter.

## Topics Covered

- JavaScript basics
- Variables and data types
- Operators and conditions
- Loops and iterations
- Functions
- Basic DOM usage

## Repository Structure

```text
Javascript/
├── ch1.html
├── ch1.js
├── ch2.html
├── ch2.js
├── ch3.html
├── ch3.js
├── ch4.html
└── ch4.js
```

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shubham-nov06/Javascript.git
cd Javascript
```

### 2. Run an example

Open any `chX.html` file in a browser. The linked `chX.js` file contains the JavaScript implementation.

## Requirements

- A modern browser such as Chrome, Edge, or Firefox
- A text editor such as VS Code

## Learning Purpose

This repository is intended for practicing JavaScript concepts step by step and testing small code examples.
